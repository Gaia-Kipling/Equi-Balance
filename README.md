# Equi Balance — Shopify Practice Theme

A custom Online Store 2.0 theme created around the Equi Balance brand direction.

## Brand
- Name: Equi Balance
- Slogan: Supporting Better Movement
- Primary visual direction: deep forest green, warm ivory, champagne gold
- Logo system: primary, stacked/secondary, icon, horizontal

## Current website direction
- Premium but practical equestrian aesthetic
- Product-first structure
- Designed to grow beyond balance pads into saddle pads, half pads, rehabilitation and training products
- Initial product information is deliberately treated as development/placeholder content

## Important
The balance pad specifications in the project should not be treated as final commercial claims. Replace prototype/placeholder information only after product testing and supplier verification.

## Shopify structure
This is an Online Store 2.0-style theme using JSON templates and sections. Shopify's current theme architecture supports layouts, sections, section groups, snippets, assets, config and JSON templates.

## Suggested setup
1. Create/open the Shopify development store.
2. Upload this ZIP through the theme editor as an unpublished theme.
3. Open Customize.
4. Add the Equi Balance logo in Theme Settings or keep the supplied logo asset.
5. Create the pages linked in the navigation: Our Story, Why Equi Balance, Contact and Coming Soon.
6. Create the initial product when the product development work is ready.
7. Replace the homepage placeholder copy/images with validated product information.

## Practice-store approach
This theme intentionally avoids pretending the product is commercially ready. It provides the branded storefront structure while the physical product is still being developed.
